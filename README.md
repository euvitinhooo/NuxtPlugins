# NuxtPlugins
## Comandos
- /nuxt reload (Permissão: nuxtcommand.adm.reload).
## Funcionalidades
- Funciona em BungeeCord e Spigot (Futuramente será compatível em Velocity, WaterFall, Folia, Paper 1.20X e Mohist).
- Otimizado para o desenvolvimento de novos plugins.
- Extremamente otimizado.
- Com o novo Loader, os futuros plugins irão ter API pública.
## Dependências
- Este plugin não precisa de dependências.
